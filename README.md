# Space Collector — учебный проект на Unity + C#

Простой учебный 2D-проект для вводного мастер-класса по разработке игр на **Unity** и **C#**.

Игрок управляет персонажем, собирает кристаллы и уворачивается от астероидов.  
Цель игры — собрать нужное количество кристаллов и не столкнуться с астероидом.

Проект специально сделан максимально простым, чтобы его можно было запускать даже на слабых компьютерах и использовать для первого знакомства детей с Unity.
